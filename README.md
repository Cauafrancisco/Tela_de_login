Projeto de Autenticação (Login & Cadastro)
Interface web limpa e estilizada para páginas de login e cadastro de usuários, focada em boas práticas de estruturação de camadas (z-index), layouts flexíveis e transições suaves.

Recursos
Layout Responsivo: Estruturado com Flexbox e centralização fluida para diferentes tamanhos de tela.

Imagem de Fundo Fixa: Fundo em tela cheia otimizado com pointer-events: none para evitar interferência nos cliques do usuário.

Componentes Estilizados: Cartão translúcido com efeitos visuais e botões interativos com transições de cor suaves.

Links de Navegação Inferior: Organização flexível para recuperação de senha e alternância entre as telas de acesso.

Tecnologias Utilizadas
HTML5 (Semântica estrutural)

CSS3 (Flexbox, variáveis visuais, transições e controle de empilhamento)
